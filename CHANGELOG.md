### Added

- Initial release of Posture Correction System.
- Real-time posture analysis using MediaPipe Pose.
- Geometric angle calculation for neck tilt and shoulder slope.
- Audio alerts for sustained bad posture.
- Configurable thresholds via environment variables.
- Web API with health check, frame analysis endpoint, and WebSocket stream.
- Docker image for containerized deployment.
